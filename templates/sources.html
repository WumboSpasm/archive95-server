Backlog

The following data sources are planned to be added to Archive95 sometime in the future:

  • World Online Digest (All Archived Volumes) - CD-ROMs containing offline web content which were sent out via an American subscription service. Most volumes between 1999 and 2000 are available online.
  • Dokan N° 1-34 and Dokan Especial N° 1-6 - Coverdiscs belonging to a Spanish anime/manga magazine, which included offline web content from 1998 to 2001.
  • Minami 2000 N° 0-10 - Coverdiscs belonging to a Spanish anime/manga magazine, which included offline web content from 1998 to 1999. It shares the same publisher as Dokan.
  • Minami Vol. II N° 1-17 - Coverdiscs belonging to a Spanish anime/manga magazine, which included offline web content from 2000 to 2001. It is a reboot of Minami 2000 with an altered name.
  • Revista Arroba N° 8-46 - Coverdiscs belonging to a Spanish computer magazine, which included offline web content from at least 1998 to 2001. A significant amount of volumes are not currently available online.
  • Komputer for Alle (Most Volumes up to 1999) - Coverdiscs belonging to a Danish computer magazine with Swedish, Finnish and Norwegian editions, which frequently included offline web content from 1997 to 1999.
  • CU Amiga Magazine Super CD-ROM 3-27 - Coverdiscs belonging to a British Amiga magazine, which included offline web content from 1996 until its discontinuation in 1998.
  • Online Praxis 2/97-2/98 - Coverdiscs belonging to a German internet-focused magazine, which included offline web content from 1997 to 1998.
  • CoolPage 14-16 - Coverdiscs belonging to a Taiwanese internet-focused magazine, which included offline web content from 1997 and 1998 in the three volumes that are available online.
  • Internet Cyber Guide N° 2-3 - Coverdiscs belonging to a French internet-focused magazine, which included offline web content from 1997 in the two volumes that are available online.
  • Chip Kasım 1999 - Coverdisc belonging to the Turkish edition of the Chip computer magazine, which included offline web content pertaining to Star Wars.
  • Intermedia 1/98 - Coverdisc belonging to a Polish internet-focused magazine, which included offline web content.
  • net.disc 10/97 - Coverdisc belonging to an American internet-focused magazine, which included offline web content.
  • Revista do CD-ROM N°28 - Coverdisc belonging to a Portuguese computer magazine, which included offline copies of the Euronet website as well as some linked pages from 1997.

Needs Research

The following data sources have not yet been fully researched to determine if they can be feasibly added to Archive95:

  • Various Versions of Crystallographic Nexus Software Library - CD-ROMs containing offline copies of academic web resources. This open directory appears to be missing several versions.
  • Various Volumes of Magazyn Amiga - Coverdiscs belonging to a Polish Amiga magazine, which included offline web content.
  • Comtek 2000 Multimedia Catalog - CD-ROM distributed in Russia at the Comtek 2000 computer expo, which included offline web content.
  • MacWorld Ultimate PowerMac CD - Coverdisc belonging to an American Apple-focused magazine, which included website reviews accompanied by offline copies of their homepages.
  • NASA HPCC Information On-Line '97 - CD-ROM containing offline copies of NASA HPCC web resources.
  • Elf Fan Club Vol. 33 - CD-ROM containing a copy of the website of Elf Corporation, a Japanese game studio, from 1998.
  • Amptron World on CD - CD-adapted version of the website of Amptron, an American electronics manufacturer, from 1998.
  • 24 Hours in Cyberspace Collector's Edition - CD-adapted version of the website of the same name from 1996, formerly located at cyber24.com.
  • A Teacher's Guide to the Holocaust Version 1.0 - CD-adapted version of the website of the same name from 1998. The current version of the website can be found here.

Won't Add

The following data sources are either impossible to add without some grand revelation, or extremely low priority for one reason or another:

  • Various Internet Explorer CDs (1, 2, 3, 4, 5) - CD-ROM distributions of early versions of Internet Explorer, which included CD-adapted demos of numerous websites. There are no explicit URL maps, and files are stored in a flat structure with their names either truncated or converted to 8.3 filenames, making it very difficult to confidently reverse-engineer their original URLs.
  • Various Intel Developer CDs (1, 2, 3, 4, 5) - CD-adapted versions of significant portions of Intel's website. There are no explicit URL maps, and all filenames are truncated and stripped of special characters, making it very difficult to confidently reverse-engineer their original URLs. Additionally, the original headers and footers of each page have all either been modified or removed.
  • Various Sega Saturn Internet CDs (1, 2, 3) - CD-ROM distributions of internet software for the Sega Saturn from 1996 and 1997, which included CD-adapted demos of numerous Japanese websites. There are no explicit URL maps, and files are stored in a flat structure with truncated names, making it impossible to confidently reverse-engineer their original URLs.
  • Various Volumes of PC Media (1, 2, 3) - Coverdiscs belonging to a Spanish computer magazine, which frequently included offline web content. Several volumes used InContext WebAnalyzer for this purpose, which presents captured data in a numeric file structure but creates detailed report pages mapping each file to its original URL. Unfortunately, these report pages are absent from the CD-ROMs, making it impossible to determine the original URLs.
  • Internet 1996 World Exposition - The official website for the first "internet world's fair", spearheaded by Public.Resource.Org founder Carl Malamud. This is a raw dump of the website's filesystem obtained from a public AWS bucket that went online in 2017, containing loose files, uncompiled scripts and decades of guestbook spam. Coupled with the sheer size of the website, restoring it to how it functioned in 1996 would be a whole other project in itself.
  • Out-of-the-Net - CD-ROM containing extensive captures of several websites from 1996. There are no explicit URL maps, and all filenames are truncated, stripped of special characters and numerated in the case of naming conflicts, making it very difficult to confidently reverse-engineer their original URLs.
  • NEC Internet Tutor - CD-ROM containing extensive captures of several Japanese websites from 1996. There are no explicit URL maps, and all filenames are truncated, making it very difficult to confidently reverse-engineer the original URLs.

Most Wanted

If you have any information concerning the whereabouts of the below CD-ROMs, please reach out using one of the methods listed in the "About the Author" section of the About page.

  • Missing Volumes of World Online Digest - These are CD-ROMs containing offline web content which were distributed via a subscription service. Many have already been preserved online and are in the backlog; however, there appears to be an equal if not larger amount of volumes that have not yet been archived, primarily from 1998 and earlier. Information online is scarce, although its website can be found in the Wayback Machine here.
  • Missing Volumes of Dokan - This was a Spanish anime/manga magazine whose coverdiscs included offline web content from 1998 to 2001. While it has otherwise been very thoroughly archived, Dokan N°26 and Dokan Especial N°2 are both not available online. Scans of Dokan N°26's front cover and disc can be found on this page.
  • Missing Volumes of Revista Arroba - This was a Spanish computer magazine whose coverdiscs included offline web content from at least 1998 to 2001. A whopping 25 coverdiscs which are likely to include web content have not yet been archived, specifically: volumes 1-7, 9-12, 14-21, 24-27, 31, and 47.
  • Missing Volumes of CoolPage - This appears to have been a Taiwanese internet-focused magazine, of which the coverdiscs for volumes 14, 15 and 16 exist online and all include web content. There does not appear to be any surviving information online about previous or later volumes.
  • Missing Volumes of PC Media - This was a Spanish computer magazine whose coverdiscs frequently included offline web content. The coverdiscs for volumes 24-25, 28-30, 32-37, 39-40, and potentially 42 and beyond have not been archived and are likely to contain web content.
  • Missing Volumes of cd.web - This was a Spanish internet-focused magazine which shared the same publisher as Dokan and Minami. There is extremely little information about this magazine online, outside of the coverdisc for the first volume, which is present in Archive95.
  • The Silicon Surfer World Wide Web Demo CD II - This mysterious CD-ROM was sold on Ebay in March 2026. No other information exists about it online, although it is likely an updated version of the Silicon Surf CD already present in Archive95.
