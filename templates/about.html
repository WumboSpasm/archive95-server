About Archive95

Background

The Wayback Machine is the world's foremost web archive, with a collection dating all the way back to 1995. However, like all things, it is not perfect; pages go unnoticed and assets slip through the cracks. Moreover, the web existed for several years prior to the Wayback Machine's earliest captures.

This begs the question: what, if anything, can be done to fill in these gaps at a large scale?

Goals of Archive95

Archive95 aims to provide its own reconstruction of the early web using data from often-overlooked sources. This includes:

  • CD-ROMs containing offline copies of web content
  • Preserved browser caches
  • Loose archives on the live web which are at serious risk of disappearing
  • Usenet messages (yes, really)

These data sources often touched upon certain areas of the web to a deeper extent than the automated, untargeted crawls that encompass most of the Wayback Machine; many sources even predate it outright. Unfortunately, the extreme variance in how this data is presented across sources means that adding them to Archive95 is usually far from a straightforward task. Commonly-encountered issues include:

  • Pages being modified in a way that causes visual deformities
  • Links to unavailable pages being commented out or pointed to an error page
  • Images being stored in a flat file structure with no indication of their original URLs
  • Corrupted and/or partially downloaded files

A significant amount of effort is put into identifying and fixing issues such as these, in order to provide an accurate representation of these pages as they originally appeared on the web.

Non-Goals of Archive95

Archive95 is not hugely concerned with material that is already thoroughly preserved and easily accessible; for example, CERN's W3 project website from 1992 and the Stanford Web Archive Portal. The primary focus of this project is data that is in desperate need of mirrors or is otherwise difficult to track down on its own.

Additionally, as an archive of the early web, material which is dated well past the turn of the century is not considered high priority for inclusion in Archive95.

Features

Archive95 offers a timeline-based interface for displaying archived URLs, similar to the Wayback Machine. Because all files are part of the same web of links, it is, for example, possible for image assets missing from one data source to be supplied by another.

Additional quality-of-life features include a search engine, a directory browser, and the ability to view all pages which link to a particular file. A JSON API is also available.

Browser Compatibility

In the interest of making Archive95 as easy to use in retro computing environments as possible, a lightweight, pure-HTML interface is served when connecting from a legacy web browser. Despite its basic appearance, it provides a virtually identical feature set as its modern HTML5 counterpart, and functions exceptionally well on browsers as old as Netscape b0.5 from September 1994 (although even older browsers should at least be able to access the site).

When viewing archived pages on modern browsers with the navigation bar enabled, a small amount of JavaScript is used to ensure that links behave properly, especially on pages which use frames. Disabling JavaScript may cause some links to unintentionally duplicate or hide the navigation bar, or in the case of frames, update the wrong part of the page.

Data Integrity

Specific information about the integrity of each data source, as well as any remediations applied, can be found through the Data Sources page. Unfortunately, not all data integrity issues are fixable, and this often results in undesirable quirks while browsing the archive, such as the following:

  • Many pages contain links which point to a "dead-end" page, rather than their intended destinations. This usually happens when a data source originally intended for offline use is modified to point any links to content not available locally to an error page.
  • Many files lack their original URLs, instead being referred to by their raw paths within the data source. These are called "orphan files", and they appear most frequently when data sources store their contents in a custom file structure that does not resemble their original URLs, rendering them irrecoverable.
  • Many URLs do not display an archival date that is accurate to the day. This is because a large number of data sources do not provide reliable means of gathering the exact archival dates of their contents, whether through file timestamps or otherwise, so they are assigned an approximate month or year around which they appear to have been archived.

Project History

Archive95 was started in 2021 out of a newfound fascination with "internet CDs", an obscure genre of CD-ROMs whose purpose was to provide offline computer users a taste of the fledgling web. It was originally titled wwwdirectory-js and consisted of material from a single source, World Wide Web Directory. It was also very basic at a technical level, pulling data from an Internet Archive item on the client-side and rendering it on-the-fly using JavaScript.

In 2022, the project was revamped and rebranded as Archive95, incorporating additional material from Einblicke ins Internet, although technically it was more or less the same. The name and logo were inspired by Windows 95, with the "95" also referring to how the archive's contents originated from the year 1995 (although this is no longer entirely true).

In 2024, the project was completely re-engineered from the ground up, bringing it much closer to its current-day state and adding several new data sources in the process. The archive95.net domain name was registered shortly after in 2025. In 2026, the codebase was rewritten once again (hopefully for the last time) and development has been steady ever since.

Contributing

Tracking down usable data for Archive95 is an exhausting and time-consuming task, especially with language barriers at play. As such, any help on that front is greatly appreciated, whether it comes in the form of direct data contributions or simply pointers to the right places. See the "About the Author" section below for ways to reach out.

Information about particularly sought-after data sources can be found in the "Most Wanted" section of the Data Sources page.

About the Author

Archive95 is a passion project of Ian Edmonds, also known as WumboSpasm. Other projects he has worked on include Greetmaster (an e-card museum) and Flashpoint Archive. He does not use artificial intelligence tools.

If you have any questions, feature requests or bug reports - or if you would like to suggest or contribute data for the archive - feel free to open an issue in the GitHub repository, or send an email to admin (at sign) archive95 (period) net.
